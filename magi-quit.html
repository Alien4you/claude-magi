Core is correct and tested; the failure is an install-mode mismatch, not a broken design

  • major ~/.claude/skills/magi Root cause found: the repo is symlinked into ~/.claude/skills/, the skills-directory path. It loads SKILL.md only and does not scan agents/. This is a user install-method error, not a defect in the built code.
  • major SKILL.md:88 Second consequence of the same mismatch: ${CLAUDE_PLUGIN_ROOT} is only defined for plugin-provided skills. Under the skills-directory install it expands empty, so step 4 would have run `node /bin/magi-deliberate`.
  • major .claude-plugin/plugin.json Hybrid layout: a root SKILL.md (skills-directory convention) plus .claude-plugin/plugin.json and agents/ (plugin convention), with no skills/ directory. Neither install mode delivers the skill and the agents together. The fix is moving SKILL.md into skills/magi/, not a redesign.
  • major test/ All 72 tests cover the tally and the presentation layer. Zero cover the orchestration path. The only untested subsystem is the one that failed on first execution.
  • minor lib/verdict.mjs:103 summarize() prints 'unanimous' whenever dissenters is empty, so REJECT/ABSTAIN/ABSTAIN renders as '(1-0) — unanimous' while result.unanimous is false. Label only, never the decision.
BALTHASAR • 2 SAFETY / HARM 否定 · NEGATIVE

Nobody is harmed if this continues; the injection defenses hold. Do not abandon it.

  • major agents/*.md:4 All three units are granted Bash, yet their job is to read untrusted diffs that can carry prompt injection. A reviewer needs no shell. Drop Bash from all three frontmatters and the untrusted-input path ends at read-only tools.
  • minor lib/sound.mjs:268 playerFor() interpolates the cue path into a single-quoted PowerShell string. A sound directory containing an apostrophe breaks the quoting and executes on Windows. Operator-controlled, but it is the only string-concatenated command in the codebase.
  • note lib/frames.mjs:75 sanitize() verified against OSC 0/52, CSI, DCS, C1, backspace and bracketed-paste payloads: the trailing control-range pass strips every residual ESC, so the filter fails closed.
  • note NOTICE IP exposure is bounded and lands only on the author. No GAINAX/khara assets ship. The worst realistic outcome is a takedown of one public repo, with no user data and no third party affected. Not a safety reason to stop.
